# Tavern Chat Reader · 酒馆聊天记录查看器

> 把酒馆聊天记录带出酒馆：一个 HTML 文件，一本随身可翻的离线故事书。

![Offline](https://img.shields.io/badge/Offline-100%25-2ea44f?style=flat-square) ![No dependencies](https://img.shields.io/badge/Dependencies-0-8250df?style=flat-square) ![Single file](https://img.shields.io/badge/Reader-Single%20HTML-f0883e?style=flat-square) ![License](https://img.shields.io/badge/License-MIT-6f42c1?style=flat-square)

**导入 TXT，读回每一句心动。**

这是一个为酒馆（SillyTavern）聊天记录准备的独立阅读器。它不需要安装酒馆、不需要服务器、不需要联网：把 `index.html` 发到任何一台电脑或手机，用浏览器打开，就能继续读。

## 为什么它很酷

- **真正离线**：TXT、正则、皮肤、书架、阅读设置都留在本机浏览器。
- **正则不是摆设**：可导入酒馆正则 JSON，把状态栏、卡片和前端代码块按原样渲染出来。
- **两种阅读方式**：卷轴连续阅读，或无上下滑动的横翻分页；横翻还能按页或按章节跳转。
- **手机也像阅读器**：点正文中央唤出半透明上下控制栏，单手调设置，不挤占故事。
- **排版可玩到细节**：字号、字体、字重、颜色、行高、段距、缩进、宽度、边距与两端对齐即时生效。
- **皮肤不是换个颜色**：可导入背景图、透明度、控件文案/图标、TTS 外观和自定义 CSS；排版数值也能写进皮肤。
- **自己的小书架**：导入过的记录会留在本机，下次不用重新找 TXT。
- **朗读前先验稿**：TTS 会展示过滤标签后的最终文本，确认后才发送给语音服务。

## 30 秒开始阅读

1. 下载或复制本仓库的 `index.html`。
2. 用 Chrome、Edge、Firefox 或手机浏览器直接打开它。
3. 导入酒馆导出的 `.txt` 聊天记录。
4. 需要还原状态栏/前端卡片时，再导入对应的正则 JSON。
5. 点“文字”“外观”“朗读”，把这本故事调成自己的样子。

> 不需要安装 Node.js、Python、酒馆或任何插件。

## 功能地图

| 模块 | 能做什么 |
| --- | --- |
| TXT 与书架 | 导入、编辑、保存、再次打开本机聊天记录 |
| 正则渲染 | 导入正则 JSON；完整 HTML 前端块在隔离区域中渲染 |
| 阅读 | 卷轴 / 横翻、章节识别、页码输入跳转、按章翻页 |
| 文字 | 自定义字体族、导入字体、字号/字重/颜色、行高/段距/缩进/宽度/边距、两端对齐 |
| 正文标签 | 例如 `<status_bar>` 可设为完整屏蔽，或只去标签、保留内容 |
| 外观 | 内置主题、外部皮肤、背景图、背景与阅读面板透明度、全屏 |
| TTS | 标签筛选、标签自定义、发送前预览确认、MiniMax 语音合成 |

## 本机保存与隐私

- 聊天书架、正则、皮肤和阅读偏好保存在**当前浏览器**。
- 导入字体会保存到浏览器本机数据库；换电脑、换浏览器、无痕窗口或清空站点数据后需要重新导入。
- 阅读器本身不会上传 TXT。
- 只有你主动使用 TTS 并确认发送时，选中的朗读文本才会发给你配置的 MiniMax 服务。

## 皮肤与正则

- 皮肤说明：[docs/皮肤制作说明.md](docs/皮肤制作说明.md)
- 示例皮肤：[examples/示例-雾蓝皮肤.json](examples/示例-雾蓝皮肤.json)
- 可将皮肤说明整段交给任意 AI，让它生成可直接导入的 JSON。

皮肤可预设正文的字号、行高、段距、缩进、宽度与边距；读者手动调节后会临时覆盖，点“文字 → 重置”即可回到当前皮肤的默认值。
