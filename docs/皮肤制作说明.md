# 聊天记录查看器皮肤制作说明

皮肤不只改配色。它可以正式修改背景图、背景透明度、各层透明度、正文颜色、字体、字重、行高、段距、缩进、正文宽度与边距、圆角、按钮文案/Unicode 图标、朗读（TTS）面板，以及用 `css` 重做查看器的控件外观和布局。

保存为 UTF-8 编码的 `.json` 文件后，在查看器顶部点“外观” → “导入皮肤”即可。一次可导入多份文件；一个 JSON 文件也可以使用 `{ "skins": [ ... ] }` 放入多套皮肤。

## 可直接交给 AI 的要求

> 为“聊天记录查看器”生成一份**完整可导入的皮肤 JSON**。只输出合法 JSON，不要 Markdown 代码块、解释、HTML 或 JavaScript。使用 `format: "txt-chat-viewer-skin"` 与 `version: 1`。皮肤应包含中文 `name`、`description`、`colorScheme`（`dark` 或 `light`），并尽量提供 `background`、`opacity`、`layout`、`reading`、`tts`、`controls`、`icons`、`tokens` 和少量 `css`。它必须重做阅读器外壳，而不只是换颜色：设置背景图或渐变、背景透明度、正文字体、字重、颜色、行高、段距、缩进、正文宽度与边距、面板透明度、横翻页外观、手机半透明菜单、朗读设置面板、按钮圆角与字体。`icons` 使用 Unicode/emoji 文本图标；若需要 SVG/图片图标，请放到 `css` 的 `background-image` 中。CSS 只能是普通 CSS 字符串，不能包含 `<style>`、`<script>`、`@import`、远程字体或远程资源。请保持文字可读、触屏控件可点，并让手机菜单、横翻页和朗读面板也可用。

## 背景与透明度

`background.image` 可以是：

- `linear-gradient(...)`、`radial-gradient(...)` 等 CSS 渐变；
- `url(\"背景.jpg\")`；
- 原始图片地址或 `data:image/...;base64,...`。原始地址会自动当作 `url(...)` 使用。

为了在没有网络的电脑和手机上都可用，优先用渐变或 `data:` 图片。也可以把背景图和查看器 HTML 放在同一文件夹，再使用 `url("背景.jpg")`；转移文件时要一起转移。不要使用网络图片、`@import` 或外部字体。

`background.opacity` 控制背景图本身透明度；`opacity` 里的五项分别控制阅读器主面板、工具栏、展开菜单、横翻纸页和手机菜单的透明度。数值可写 `0` 到 `1`，也可写如 `85%`。

## 查看器内的即时调节

打开查看器的“外观”菜单，可以直接导入 PNG、JPG、WebP、GIF、AVIF 或 SVG 背景图，也可以分别调节“背景图透明度”和“阅读背景透明度”（后者同时影响卷轴阅读器与横翻纸页）；打开“文字”菜单，可以切换字体、字号、字重、字体颜色和自定义 CSS 字体族，并即时调节行高、段距、首行/整段缩进、正文宽度、两侧边距与两端对齐。强制段落排版会按空行分段；“去掉空行”会压缩空白行但仍保留可调的段距；“换行整理为段落”会把每个非空换行视为一段。它们会立即生效并尽量保存在当前浏览器。

“文字”菜单还可以导入 `.ttf`、`.otf`、`.woff` 或 `.woff2` 字体，并立即用于卷轴和横翻正文。字体文件会保存到**当前浏览器、本机的数据库**，刷新或重新打开同一份 HTML 后会自动恢复；它不会被塞进皮肤 JSON，也不会跟随 HTML 文件复制到另一台设备。清除该浏览器的网站数据、使用无痕窗口，或本机存储空间不足时，字体需要重新导入。

阅读器的“目录”会自动识别独占一行的 `第 1 章 …`、`# 标题`、`Chapter 1`，以及“序章 / 尾声 / 番外”等标题；点击目录项可跳到卷轴位置或横翻页。横翻模式的页码中间还有“按页翻 / 按章翻”开关：切到“按章翻”后，左右按钮、左右滑动和键盘方向键会直接跳到上一章或下一章；手动输入页码仍然按实际页码跳转。章节标题会从新的一页开始。皮肤可用 `controls.chapters` 与 `icons.chapters` 改写目录按钮。

手动设置会暂时优先于皮肤预设。背景图、背景透明度、阅读背景透明度和字体颜色可分别恢复为“跟随皮肤”；“文字”菜单的“重置”会让字体和排版数值重新跟随皮肤的 `reading` 预设或对应 `tokens`。

图片会转成仅在本机浏览器使用的数据图片，不会上传。过大的图片有可能无法被浏览器长期保存，但本次打开仍可使用。

## 控件、图标与布局

`controls` 可替换控件文字，`icons` 会加在同名控件文字前；它们可使用任意 Unicode、emoji 或符号。可用键：

`changeFile`、`scroll`、`flip`、`chapters`、`tts`、`rules`、`appearance`、`text`、`fullscreen`、`exitFullscreen`、`importRule`、`importSkin`、`previous`、`next`、`previousShort`、`nextShort`、`previousChapter`、`nextChapter`、`pageNavigation`、`chapterNavigation`、`removeRule`、`removeSkin`。

其中 `tts` 对应顶部的朗读按钮；可同时写入 `controls.tts` 和 `icons.tts`。

`layout` 支持：

- `readerRadius`：阅读器大圆角；
- `controlRadius`：普通按钮圆角；
- `uiFont`：菜单和控件字体；
- `contentFont`：TXT 正文字体。

`reading` 是正文预设，支持：

- `font`：正文的 CSS 字体栈，与 `layout.contentFont` 作用相同，但优先级更高；
- `weight`：正文的字重，可写 `100` 到 `900` 的整百数值，例如 `400`、`600`、`700`；
- `color`：卷轴正文颜色；未指定 `flipColor` 时也会用于横翻正文；
- `flipColor`：横翻正文颜色。
- `size`（或 `fontSize`）：正文字号，单位为 `px`，范围 `13` 到 `28`；
- `lineHeight`：行高倍数，范围 `1.1` 到 `3`；
- `paragraphSpacing`：段后距离，单位为 `em`，范围 `0` 到 `3`；
- `paragraphIndent`：首行或整段缩进数值，单位为 `em`，范围 `0` 到 `4`；
- `width`（或 `contentWidth`）：正文最大宽度，单位为 `ch`，写 `0` 表示自适应；
- `sideMargin`（或 `margin`）：正文两侧额外边距，单位为 `rem`，范围 `0` 到 `4`。

这些数值是皮肤默认值：读者拖动相应滑块后会暂时覆盖；点“文字 → 重置”即可再次跟随当前皮肤。

## 正文标签处理

“文字”菜单底部可以添加任意正文标签名，例如 `<status_bar>`。每条规则保存在当前浏览器，并立即作用于 TXT 原文与正则渲染出的 HTML 内容：

- `完整屏蔽`：移除标签本身及其中全部内容；
- `只去标签，保留内容`：移除开/闭标签，但保留其中的正文或组件；
- `正常显示`：暂时不处理该标签；
- `×`：删除这一条规则；“清空列表”会移除全部正文标签规则。

这套规则只影响阅读显示，不会改写 TXT 原文，也不改变 TTS 自己的标签屏蔽列表。

## 朗读（TTS）面板

朗读面板默认跟随皮肤的 `--paper`、`--paper-2`、`--ink`、`--muted`、`--line` 和 `--accent`，所以只换基础颜色时也会自动保持统一。若希望朗读面板有独立外观，可增加 `tts` 对象：

- `panel`：展开后的朗读菜单底色；
- `surface`：每张设置卡片的底色；
- `input`：输入框、下拉框和标签按钮的底色；
- `ink`、`muted`：主文字和说明文字；
- `line`（或 `border`）：边框；
- `accent`：开关、选中项和主操作强调色；
- `onAccent`：强调色按钮上的文字颜色。

所有值都是 CSS 颜色字符串。尤其是浅色皮肤，请让 `ink` 与 `panel` / `surface` 有明显明暗差，并让 `onAccent` 与 `accent` 有明显对比；否则 API 密钥、模型、语速等文字会难以阅读。若需要更底层地覆盖，也可以在 `tokens` 中直接写同名变量：`--tts-panel`、`--tts-surface`、`--tts-input`、`--tts-ink`、`--tts-muted`、`--tts-line`、`--tts-accent`、`--tts-on-accent`。

若想使用真正的 SVG/PNG 图标、重排按钮、修改按钮尺寸、隐藏文字或增加纹理，请使用 `css`。它会在内置样式之后加载，因此能覆盖查看器的界面。TTS 的“发送前确认”预览弹层也会自动使用同一套 `tts` 颜色；可用下面的选择器单独微调。

常用选择器：`body`、`.reader`、`.reader-head`、`.reader-toolbar`、`.view-switch`、`.toolbar-actions`、`.chapter-menu`、`.chapter-item`、`.chapter-heading`、`.rule-menu`、`.skin-menu`、`.text-menu`、`.text-setting`、`.body-tag-row`、`.body-tag-mode`、`.rule-item`、`.skin-card`、`#tts-toggle`、`.tts-menu`、`.tts-card`、`.tts-btn`、`.tts-radio`、`.tts-chip`、`.tts-confirm-dialog`、`.tts-preview-text`、`#content`、`.flip-page`、`.flip-controls`、`.reader-controls.mobile-open`。

例如把全屏按钮改为 SVG 图标外观（示意）：

```css
#fullscreen-toggle {
  width: 38px;
  font-size: 0;
  background: rgba(255,255,255,.12) url("data:image/svg+xml,...") center / 17px no-repeat;
}
```

`css` 只写 CSS 规则本身，不要包 `<style>` 标签，也不要写脚本。

## 可直接写入 `tokens` 的变量

所有值都是 CSS 字符串；未写的项目会沿用默认值。

| Token | 控制内容 |
| --- | --- |
| `--bg`、`--paper`、`--paper-2` | 页面、主面板、工具栏基础颜色 |
| `--ink`、`--muted`、`--content-ink` | 控件、次要文字、卷轴正文文字 |
| `--line`、`--accent` | 边框与强调色 |
| `--reader-shadow` | 阅读器阴影 |
| `--preview-bg`、`--preview-code-bg` | 完整 HTML 预览区外壳/代码区 |
| `--flip-bg`、`--flip-ink`、`--flip-highlight` | 横翻页背景、正文文字和高光 |
| `--mobile-overlay`、`--mobile-panel` | 手机半透明遮罩与菜单面板 |
| `--tts-panel`、`--tts-surface`、`--tts-input` | 朗读菜单、设置卡片与输入控件底色 |
| `--tts-ink`、`--tts-muted`、`--tts-line` | 朗读面板的主文字、说明文字与边框 |
| `--tts-accent`、`--tts-on-accent` | 朗读面板的强调色与强调按钮文字 |
| `--page-bg-image`、`--page-bg-size`、`--page-bg-position`、`--page-bg-attachment`、`--page-bg-overlay`、`--page-bg-opacity` | 背景图高级覆盖 |
| `--reader-opacity`、`--toolbar-opacity`、`--menu-opacity`、`--flip-opacity`、`--mobile-panel-opacity` | 各层透明度高级覆盖（写百分比） |
| `--reader-radius`、`--control-radius` | 阅读器与按钮圆角 |
| `--ui-font`、`--content-font`、`--content-font-weight`、`--content-font-size` | 界面字体、正文字体栈、正文字重与字号（`px`） |
| `--content-line-height`、`--content-paragraph-spacing`、`--content-paragraph-indent` | 行高、段距与缩进（分别写无单位倍数、`em`、`em`） |
| `--content-column-width`、`--content-side-inset` | 正文宽度（`ch` 或 `none`）与两侧边距（`rem`） |

## 边界

皮肤会修改查看器本身的外壳、卷轴阅读、横翻模式、手机菜单和朗读面板。由酒馆正则直接渲染出来的独立前端卡片有自己的 CSS，并且会被隔离以保证渲染稳定，因此默认保留其原本设计，不会被皮肤强行覆盖。
